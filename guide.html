Comment utiliser un bot Discord

Les bots Discord se pilotent avec des commandes slash : des commandes qui commencent par /.

  1. Clique dans la zone de texte d'un salon.
  2. Tape /lanciers- : Discord affiche la liste des commandes qui commencent par ces lettres, avec leur description.
  3. Clique sur celle qui t'intéresse, ou continue à taper son nom.
  4. Certaines commandes demandent des informations complémentaires (un jeu, des noms de joueurs…). Discord affiche un champ pour chacune, avec sa description. Tu remplis ceux que tu veux, et tu laisses vides ceux que tu n'utilises pas.
  5. Appuie sur Entrée pour valider.

Ta commande et la réponse du bot apparaissent dans le salon, comme un message normal. Certaines réponses ne sont visibles que par toi (marquées « Toi seul(e) peux voir celui-ci »), d'autres sont visibles par tout le monde.

Astuce : toutes les commandes se lancent depuis le salon de la date concernée (par exemple #14-11-2026). Le bot détecte automatiquement la date à partir du nom du salon — tu n'as rien à préciser.

Voir les tables d'une date

Il n'y a pas de commande pour afficher les tables : elles apparaissent automatiquement dans le message épinglé en haut de chaque salon de date. Ce message se met à jour tout seul dès qu'une table est ajoutée, modifiée ou supprimée (depuis Discord ou depuis le site).

Tu peux aussi consulter le planning complet depuis un navigateur via le site Organisation des parties — le lien figure également en bas de chaque message épinglé.

Important : ne supprime pas le message épinglé, c'est lui qui affiche les tables en direct. Si tu le supprimes, il faudra attendre le prochain redémarrage du bot pour qu'il soit recréé.

Les commandes du bot Lanciers

/lanciers-add-table

Ajoute une nouvelle table pour la date du salon.

ChampObligatoireDescription
jeuNonEx : 40k, AoS, Kill Team...
decorsNonDécors ou terrain utilisé
joueur1 à joueur4NonNoms des joueurs

Tu peux ne remplir que les champs que tu connais déjà et compléter plus tard avec /lanciers-edit-table.

/lanciers-edit-table

Modifie une table déjà créée (par exemple pour ajouter un joueur manquant, ou changer de jeu).

ChampObligatoireDescription
tableOuiLa table à modifier. Une liste s'affiche automatiquement quand tu tapes.
jeu, decors, joueur1 à joueur4NonSeuls les champs que tu remplis sont modifiés, les autres restent inchangés.

/lanciers-delete-table

Supprime une table.

ChampObligatoireDescription
tableOuiLa table à supprimer. Une liste s'affiche automatiquement.

/lanciers-commentaire

Ajoute, affiche ou efface un commentaire général sur la date du salon (par exemple pour annoncer un tournoi, un changement d'horaire, etc.). Le commentaire apparaît directement dans le message épinglé.

ChampObligatoireDescription
texteNonLe commentaire à écrire. Laisse vide pour simplement afficher le commentaire actuel.
effacerNonMets sur True pour supprimer le commentaire existant.

Comment ça marche derrière

  • Un salon est créé automatiquement pour chacun des 10 prochains samedis. Son nom est la date au format JJ-MM-AAAA.
  • Le message épinglé en haut du salon est le seul à s'actualiser en direct. Ne le supprime pas.
  • Une fois la date passée depuis une semaine, le salon est déplacé dans la catégorie Archives (les messages restent consultables).
  • Un mois après la date, le salon est supprimé automatiquement — pense à noter ou faire une capture de ce que tu veux garder avant.
